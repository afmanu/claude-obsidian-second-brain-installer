# Empieza aquí

Este es un ejemplo sintético del resultado visual de una instalación.

El perfil de demostración organiza:

- estrategia;
- productos;
- clientes;
- marketing;
- aprendizaje.

Empieza en [[Home]] y abre Graph View para ver cómo una decisión conecta la estrategia, el producto, los clientes y una serie de contenido.

Este ejemplo no contiene las habilidades ejecutables. El instalador crea esas habilidades dentro del vault real.
