# Synthetic Demo Vault

This folder is a small fictional Obsidian vault for previewing the result before installation.

It contains no real personal information and is not a complete installed system. The command files, MCP configuration, and personalized agent instructions are intentionally omitted. Use the installer to create a working vault.

## Preview it

1. Download or clone the repository.
2. Open Obsidian.
3. Choose Open folder as vault.
4. Select examples/demo-vault.
5. Open Home.md.
6. Open Graph View to see the connections.

The fictional example uses the Spanish Entrepreneur profile and a product called Atlas Notes.

## What to notice

- Home.md acts as the entry point.
- Strategy, product, customer, marketing, and learning notes link to one another.
- Decisions keep their reason and affected areas.
- Content ideas remain connected to the product and strategy that motivated them.

Do not store personal notes in this demo folder. Create a separate vault through the installer.
