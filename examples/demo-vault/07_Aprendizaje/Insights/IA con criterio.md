# IA con criterio

Una respuesta convincente no equivale a una respuesta verificada.

El sistema debe distinguir:

- información confirmada;
- inferencias;
- preguntas abiertas;
- decisiones humanas.

Este principio afecta a [[02_Productos/Atlas Notes/Atlas Notes]] y a [[04_Marketing/Content/Serie sobre sistemas de IA]].
